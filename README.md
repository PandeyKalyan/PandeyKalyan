## 🔬 Research: Learned Image & Video Compression

My master's thesis explores adapting a learned wavelet-based video codec for **stereo image compression**.

Current research areas:
- Disparity-compensated view filtering and stereo prediction
- Closed-loop coding and lifting schemes
- Cross-view context modeling and entropy coding
- Fine-tuning learned compression models on KITTI and InStereo2K
- Rate-distortion evaluation against learned multi-view codecs using OpenMVC

**Publication:** *Learned Stereo Image Compression using Disparity-Compensated View Filtering* — A. Meyer, K. Pandey, and A. Kaup. Submitted to IEEE ICASSP 2027; under review.
